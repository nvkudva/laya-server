Laya — System One decision model running locally on your machine

It is not a chat model. It is a System One model like Jev. You send a state — any text or JSON as information context — and a set of typed questions, and it returns typed answers with calibrated probabilities in a single forward pass. This page talks to a local FastAPI server over the Jev wire API, so nothing leaves your machine. Question types: noul answers true or false, choice picks one named option, score returns the expectation over ordered levels.
