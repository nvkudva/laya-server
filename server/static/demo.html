System One decision model running locally on your machine

It is not a chat model. It is a System One model like Jev.
Send a state — any text or JSON & a set of questions, returns answers with calibrated probabilities in a single forward pass.
Question types: noul answers true or false, choice picks one named option,score returns the expectation over ordered levels.
